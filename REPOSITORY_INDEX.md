## Reading the repository labels

- **Research snapshot / notebooks:** committed research material; check the repository README for missing data, weights, modules, and environment details.
- **Publication landing page / pointer:** a record of the research and its paper; an implementation is not implied.
- **Reference fork / external collection:** upstream work used as a reference; attribution and licensing remain with the original project.
- **Document archive / coursework:** historical submitted or learning material, retained with its original history.

Repository READMEs contain the detailed setup, provenance, licensing, and intended-use notes. Category names here describe the material; they do not indicate GitHub's archived status.
