## Documentation conventions

- Package lists describe dependencies observed in committed files; they are not claimed to be tested lockfiles.
- Workflow diagrams describe committed control flow only and call out missing data, weights, modules, or environment details.
- Publication-only and PDF-only repositories are labeled clearly instead of being presented as runnable software.
- Historical notebooks, outputs, and source files are preserved in their original form.
